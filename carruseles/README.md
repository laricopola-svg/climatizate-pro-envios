# Carruseles Climatízate Pro

Imágenes de los carruseles generados por el creador de contenido.
Esta rama (`carruseles`) es independiente de la web: no afecta a climatizatepro.cl.

Cada carpeta contiene:
- `4x5_NN.jpg`: láminas para Instagram, Facebook y LinkedIn (1080×1350)
- `9x16_NN.jpg`: láminas para TikTok (1080×1920)
- `linkedin.pdf`: carrusel en PDF para LinkedIn
- `textos.txt`: texto de cada lámina y publicaciones por red
